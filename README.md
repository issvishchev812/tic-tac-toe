# tic-tac-toe

Консольная игра для двух игроков на поле 3×3 на Python.

## Как запустить

Нужен Python 3.

```bash
python main.py
```

## Как играть

1. Поле пронумеровано от 1 до 9
2. Игроки ходят по очереди: первым ходит `X`, затем `O`.
3. Введите номер свободной клетки и нажмите Enter.
4. Побеждает тот, кто первый соберёт три своих знака в ряд, столбец или по диагонали.
5. Если все клетки заполнены и победителя нет, объявляется ничья.
6. После окончания партии программа спросит, сыграть ли ещё раз: `да` начинает новую игру, `нет` завершает программу.

## Структура кода

- `input_check` — проверка ввода номера клетки
- `rules` — ход игрока и смена очереди
- `print_board` — вывод поля
- `win` — проверка победителя
- `draw` — проверка ничьи
- `main` — игровой цикл и новая партия
